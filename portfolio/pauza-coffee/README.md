# ПАУЗА — демо-сайт кофейни

Второй проект для портфолио: адаптивный лендинг вымышленной городской кофейни в Ставрополе.

## Что показывает проект

- самостоятельное визуальное направление, не похожее на STAV DETAIL;
- адаптивную вёрстку без фреймворков;
- интерактивное меню на JavaScript;
- мобильную навигацию;
- отображение текущего статуса работы;
- демонстрационную форму бронирования;
- оптимизированные оригинальные изображения.

## Файлы

- `index.html` — структура и контент;
- `styles.css` — визуальная система и адаптивность;
- `script.js` — меню, навигация, часы работы и форма;
- `assets/hero.webp` и `assets/menu.webp` — изображения, созданные для этого демо.

## Запуск

Откройте `index.html` в браузере или запустите простой локальный сервер из этой папки.

## Важно

Кофейня, адрес, телефон, меню и цены вымышлены. Форма ничего не отправляет и нужна только для демонстрации интерфейса.
