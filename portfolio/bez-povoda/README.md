# «Без повода» — демонстрационный сайт цветочной мастерской

Третий пример портфолио для локального бизнеса. Мастерская, ассортимент и цены вымышлены. Страница показывает, как можно представить товар, помочь посетителю выбрать настроение и собрать заявку.

## Проверка

Откройте `index.html` в браузере. Проверьте:

1. На широком и узком экране текст и фотографии не выходят за границы.
2. На телефоне меню открывается и закрывается.
3. Фильтры «Все букеты», «Нежно», «Ярко» скрывают и показывают нужные карточки.
4. Кнопка «Хочу похожий букет» выбирает букет в форме.
5. Форма сообщает, что заявка не отправляется. В этой демо-версии нет сервера и не собираются данные посетителей.

## Файлы

- `index.html` — содержание и структура страницы.
- `styles.css` — оформление и адаптация под экран.
- `script.js` — мобильное меню, фильтр и демонстрационный сценарий заявки.
- `assets/` — созданные для демо фотографии букетов.

Изображения созданы встроенным инструментом ImageGen. Промпты: предметная съёмка трёх букетов на ярком синем фоне; первый — коралловые ранункулюсы, жёлтые космеи и сиреневый душистый горошек, второй — светлая эустома и тюльпаны, третий — бордовые георгины и коралловые розы. Все изображения без текста и логотипов.

## Если публиковать на Render

После отправки этой папки в GitHub создать **Static Site**: ветка `main`, Root Directory `portfolio/bez-povoda`, Build Command `echo ready`, Publish Directory `.`. Переменные окружения не нужны. Это разместит только демонстрационную версию без отправки заявок.
