# Общий контекст проекта

Этот репозиторий — рабочий проект пользователя для выхода на первые заказы в веб-разработке через создание лендингов для малого бизнеса.

Перед началом любой задачи в этом проекте:

1. Прочитай `PROJECT_CONTEXT.md` и `LEARNING_ROADMAP.md`.
2. Объясняй новые термины простым русским языком.
3. Не только пиши код, но и кратко объясняй пользователю, что изменено и чему на этом примере стоит научиться.
4. Сохраняй рабочий сайт и интеграцию Telegram. Не помещай токены, пароли и другие секреты в Git.
5. Для коммерческих материалов не выдумывай отзывы, результаты, клиентов или гарантии.
6. Предпочитай небольшие, проверяемые изменения и после них запускай подходящую проверку.

Главная цель: получить первые небольшие оплачиваемые заказы, одновременно сформировав самостоятельные навыки HTML, CSS, JavaScript, Git, API, деплоя и общения с клиентами.
