# Карточки для объявления на Авито

Загружать изображения в этом порядке:

1. `01-cover.png` — главная обложка объявления.
2. `02-stav-desktop.png` — демо-проект детейлинга на компьютере.
3. `03-stav-mobile.png` — мобильная версия детейлинга.
4. `04-pauza-desktop.png` — демо-проект кофейни на компьютере.
5. `05-pauza-mobile.png` — мобильная версия кофейни.
6. `06-included.png` — состав стартового проекта.

Все коммерческие утверждения соответствуют текущему предложению: стоимость от 7 000 ₽, ориентир 2–4 рабочих дня после получения материалов и предоплаты. Оба примера явно обозначены как демонстрационные проекты.

Файл `cards.html` — редактируемый исходник карточек. Папка `source` содержит реальные снимки двух демо-сайтов.
